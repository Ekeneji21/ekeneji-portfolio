# Ekeneji Tanaka Gomo — Portfolio

A responsive personal portfolio for remote IT support and help desk roles, built with React, TypeScript and Vite.

## Run locally

```sh
npm install
npm run dev
```

## Build and check

```sh
npm run build
npm run lint
```

## Portfolio content

- Update support areas, ticket process, skills, projects, roles and coursework in the arrays at the top of `src/App.tsx`.
- The "View CV" button opens `public/ekeneji-cv-preview.png`. Replace it with a PDF and update the link when one is available.
- The contact form validates the fields in the browser and creates a draft in the visitor's email application. It does not send or store messages on a server.
- Project images live in `public/projects/`. The Titfaz Construction cover is an illustration, as the live site blocks screenshots.

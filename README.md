# Ekeneji Tanaka Gomo — Portfolio

A responsive personal portfolio built with React, TypeScript and Vite.

## Run locally

```sh
npm install
npm run dev
```

## Build and check

```sh
npm run build
npm run lint
```

## Portfolio content

- Update project details, links, skills and coursework in `src/App.tsx`.
- The CV button downloads `public/ekeneji-cv-preview.png`, the supplied CV screenshot. It is a PNG preview, not the original PDF.
- The contact form validates the fields in the browser and creates a draft in the visitor's email application. It does not send or store messages on a server.
- Project images in `public/projects/` are screenshots captured from the live apps and the public CrestMart/Agrotek repositories, or previews published by Crestline Systems. Titfaz Construction blocks reliable screenshot access, so its visible project cover is an explicitly labelled illustration rather than a claimed website screenshot.
